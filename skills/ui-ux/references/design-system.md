# 设计系统提取

把参考中的重复规律映射到当前项目，形成可复用的视觉规则。保留用户指定的品牌和布局约束。

## 收集可比较的依据

1. 选取本次需要的页面、基础控件及其状态，不默认研究整个产品。
2. 对齐参考与实现的视口、容器尺寸、缩放和主题。文字度量不一致时，再检查字体及回退字体。
3. 能查看源码时，读取实际生效的变量和计算样式。只有截图时，把推测尺寸和颜色标记为估计值。
4. 对照多个同类实例，区分组件规则与一次性的内容差异。不要把截图中的每个像素都变成独立变量。

## 提取与映射

下表描述语义类别，不规定变量名称。沿用当前项目的命名和主题实现。

| 维度 | 应识别的规律 | 映射方式 |
| --- | --- | --- |
| 表面 | 画布、侧栏、输入区、浮层、选中区域的层级 | 复用背景变量；通过明度、边界或阴影表达各层职责 |
| 文本 | 正文、辅助信息、弱化信息、禁用内容 | 按用途映射文本变量，避免每个页面使用不同灰色 |
| 强调与状态 | 主操作、链接、选中、成功、警告、危险 | 保留品牌与状态语义；状态同时提供文字或图标提示 |
| 排版 | 字体、字号、字重、行高、行长、图标基线 | 归纳少量文本层级，先对齐度量再调整外框 |
| 空间 | 页面边距、控件内边距、组内间距、组间间距 | 从重复关系提取间距档位，保留信息分组 |
| 几何 | 控件高度、图标尺寸、不同容器的圆角 | 按控件角色与密度建立档位，避免所有元素共用一种圆角 |
| 边界与浮层 | 分隔线、卡片描边、焦点环、阴影 | 区分结构边界、交互状态和焦点提示 |

将映射记录为：

```text
观察：侧栏与主画布有轻微背景差异。
用途：区分导航与内容区域。
映射：复用已有的导航背景和画布背景变量。
缺口：仅在相关主题缺少区分时补充对应值。
```

如果已有变量与参考存在差异，先判断是用户要求的变化还是项目约束。不要为了局部还原悄悄改变全局主题。

## 保持层级与可读性

- 先用空间、排版和表面对比表达层级，再决定是否需要边框或阴影。
- 嵌套容器的重复描边会增加视觉密度。只在确实表示不同分组或可编辑区域时保留。
- 低对比背景不能成为降低文字、图标或焦点可辨识度的理由。按项目适用的可访问性要求检查对比度。
- 深色主题按语义分别设置颜色，不直接反转浅色主题。检查浮层、分隔线和禁用状态。
- 字体影响行宽、对齐和密度。先沿用已有且可用的字体，再调整间距；不依赖未提供的字体文件。
- 计时、计数和金额等频繁变化的数字，在需要稳定列宽时使用等宽数字。先检查所用字体是否支持。
- 图标按视觉中心对齐。只对必要的图标做局部补偿，不把单个图标的偏移推广为全局规则。

## 从布局约束推导响应式规则

先确定主操作和必须显示的信息，再选择压缩顺序。例如：隐藏快捷键提示、缩短辅助文字、合并次要操作，最后切换布局。

- 嵌入式工具栏和分栏优先根据实际容器空间适配。组件宽度不随视口同步变化时，可使用容器查询。
- 为可收缩文本设置合理的最小宽度与截断策略。为主操作保留必要空间。
- 图标替代文字后，保留可访问名称。被折叠的功能仍有可发现的入口。
- 断点取自内容开始冲突的位置。不要照抄参考产品的固定断点。
- 关键正文允许正常换行，不用任意截断隐藏重要信息。用实际语言、长标签和放大文字检查布局。

## 对照迭代

按布局结构、文字度量、间距密度、颜色层级、边框阴影的顺序修正。每轮在相同条件下比较相同状态。

截图只能证明当时的外观。悬停、焦点、滚动、加载和错误状态必须单独检查。
