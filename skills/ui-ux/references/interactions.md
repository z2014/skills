# 交互打磨

让反馈表达当前状态，让用户能够中断、撤销或恢复操作。只应用与本次功能有关的规则。

## 按目的选择动效

先复用项目的时长、缓动曲线和弹簧预设。没有现成规范时，从最少的反馈开始，在真实组件上调整。

| 交互 | 需要表达的内容 | 实现选择 |
| --- | --- | --- |
| 悬停、焦点、按下 | 当前目标与操作已被接收 | 颜色、透明度或轻微缩放；简单状态优先使用 CSS 过渡 |
| 标签、分段选项切换 | 选中目标发生变化 | 移动选中标记；仅在需要连续位置反馈时使用共享布局或弹簧 |
| 面板、折叠区、对话框 | 内容出现、消失或层级改变 | 保留空间关系，控制位移幅度；避免展开过程遮挡主操作 |
| 拖拽、吸附、回弹 | 直接操纵与有效落点 | 拖动时跟随指针；松开后再过渡至目标；需要越界回弹时才使用弹簧 |
| 成功、失败、加载 | 业务状态与下一步操作 | 保留文字或图标反馈；动效不能成为唯一状态提示 |

- 为需要变化的属性设置过渡，避免用 `transition: all` 把尺寸、颜色和布局意外绑在一起。
- 连续操作以最新的有效意图为准。检查旧动画结束回调是否会覆盖新状态。
- 在 `prefers-reduced-motion: reduce` 下，减少或移除非必要位移、缩放和循环效果。不要依赖动画结束事件提交业务结果。
- 渐变遮罩只用于提示还有可滚动内容。到达边缘或内容不足以滚动时，清除相应遮罩。内容与容器尺寸变化后重新计算。
- 渐隐若确实出现明显断层，再调整采样点。七档遮罩和具体弹簧系数都不是通用要求。

## 拖拽与分栏

优先复用项目已有的拖拽或分栏组件；自行实现时检查完整生命周期。

1. 按下时记录活动指针、起点与可恢复的初始值。通过移动阈值区分点击和拖拽，阈值按输入设备与项目惯例确定。
2. 使用指针捕获或既有组件保证离开手柄后仍能收到事件。只处理当前活动指针。
3. 移动时根据当前容器尺寸计算位置，并限制在有效范围。拖动过程中避免对每次位置更新再做缓动。
4. 松开时提交结果。按 Escape 取消时恢复初始值。
5. 在 `pointercancel`、丢失捕获或组件卸载时结束操作并清理状态。区分正常松开与异常中断，避免重复提交。

如果拖拽会经过 iframe，验证指针是否仍由拖拽逻辑接收。必要时临时禁用 iframe 的指针命中，或添加实际拦截事件的透明遮罩。遮罩本身使用 `pointer-events: none` 无法拦截事件；结束或中断后恢复原状态。

分栏另需检查：

- 两侧最小宽度与分隔条宽度之和大于容器宽度时，采用折叠或堆叠等明确布局，不能继续套用互相冲突的夹取边界。
- 折叠前保存合理比例，折叠后保留恢复入口。双击复位、自动吸附和折叠阈值只在需求或现有规范支持时增加。
- 可调分隔条提供键盘调整方式、可访问名称、方向和当前值。仅添加 `tabIndex` 或 `role="separator"` 不代表已支持键盘操作。

## 键盘、焦点与输入

- 优先使用已有可访问组件。模态对话框打开时把焦点放到合理位置，在模态内管理 Tab 顺序；关闭后把焦点还给触发元素或合理替代项。
- 列表、标签或网格确实需要方向键导航时，按对应组件模式实现。采用漫游焦点时，仅当前项进入 Tab 顺序；不要把一维索引增减当成二维导航。
- 检查首尾、空列表、禁用项、当前项被移除，以及需要支持的从右到左布局。Tab 应能正常离开非模态组合控件。
- 有输入法的文本输入，先检查合成状态，再处理 Enter、Escape 等快捷键。兼容性补充条件依据目标浏览器确定。
- 建议菜单打开时，先按菜单契约处理导航、确认与关闭，再判断是否提交表单。不要让确认候选项和发送操作同时触发。

## 连续内容与滚动

- 区分用户滚动与程序滚动。用户离开底部查看内容后暂停跟随，不因内容追加强行拉回。
- 回到底部或显式选择“跳至最新”后恢复跟随。底部容差和输入冷却只辅助判断，不能代替明确的跟随状态。
- 图片加载、折叠展开和容器缩放也会改变内容高度。不要只在追加文字时更新位置或遮罩。

## 行为验收示例

根据本次变更选择相关场景，不要求每个任务都执行全部检查。

| 操作 | 预期行为 |
| --- | --- |
| 动画未结束时反向操作 | 最终状态对应最后一次有效操作 |
| 开启减少动态效果 | 功能、焦点与最终布局保持正确 |
| 拖拽越过 iframe 后松开 | 操作结束，不残留遮罩或拖拽光标 |
| 拖拽中按 Escape 或中断指针 | 恢复约定状态，后续点击和拖拽仍可用 |
| 容器窄于两栏最小宽度之和 | 切换布局，主操作与恢复入口仍可访问 |
| 仅用键盘打开并关闭模态 | 焦点进入模态，关闭后回到合理位置 |
| 输入法确认候选词 | 不误提交表单或关闭外层界面 |
| 内容持续追加时向上查看 | 自动跟随暂停，用户可主动恢复 |
